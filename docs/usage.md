# 사용 설명서

## 1. 파일 받기

[실행용 HTML](https://github.com/hzuani/split-score-calculator/releases/latest/download/split-score-calculator.html)을 저장하고 Chrome 또는 Edge에서 여세요. 학교에서 브라우저의 로컬 파일 사용을 제한하면 기기 정책을 확인하세요. 인터넷 연결이나 별도 설치는 필요하지 않습니다.

## 2. 평가 설정 입력

과목의 중간고사·기말고사 시행 여부와 수행평가 개수를 선택합니다. 가중치는 반영비율(%)이며 합이 100이어야 합니다. 각 항목의 분할점수는 100점 기준으로 입력합니다.

기본값은 사용 예시입니다. 나이스의 해당 학년도·학기·과목과 최종 적용 라운드를 확인하고, 그 값으로 바꾸세요. 다른 과목이나 학기를 확인할 때도 저장된 이전 설정을 점검해야 합니다. 현재 버전은 과목별 설정을 따로 저장하지 않습니다.

항목별 분할점수를 가중 합산한 뒤 정수로 반올림해 최종 경계를 구합니다. 학생 합계도 정수로 반올림해 비교합니다. A~E 분할점수는 큰 값부터 작은 값 순서여야 하며 같은 값은 허용합니다.

## 3. 나이스 파일 준비

계산기에서 안내하는 출력 형식은 다음 경로의 일람표입니다.

나이스 → 교과담임 → 성적조회/통계 → 학기말성적조회 → 정기시험/수행평가성적일람표 → **환산점기준** 체크 → 전반출력 → XLS로 저장

나이스 화면·메뉴 명칭은 환경에 따라 다를 수 있습니다. 파일에는 성명 또는 이름 머리글이 필요합니다. 지원 확장자는 XLS, XLSX, CSV, XLSM이며 매크로는 실행하지 않습니다.

학생 점수는 이미 반영비율이 적용된 환산점이어야 합니다. 예를 들어 반영비율 30%인 평가의 파일 점수는 0~30 범위입니다. 100점 만점 원점수 파일은 사용할 수 없습니다.

## 4. 파일과 열 확인

파일을 선택하면 계산 결과가 표시됩니다. 시트가 여러 개면 읽을 시트를 선택할 수 있습니다. 기본으로 첫 번째 시트를 읽으므로 첫 시트가 안내문이면 성적 시트로 바꾸세요.

평가 열은 이름 오른쪽에서 찾아 중간고사 → 기말고사 → 수행평가 순서로 연결합니다. 화면의 열 연결 안내와 원본 파일을 대조하세요. 수동 열 연결 기능은 없습니다. 평가 순서나 출력 형식이 다르면 지원 형식으로 다시 출력해야 합니다.

모든 점수가 비어 있는 평가 열은 중간·기말·수행·평가명·반영비율 등의 머리글이 있어야 찾을 수 있습니다. 제목·머리글·통계로 제외한 행은 열 연결 안내 아래에서 확인할 수 있습니다.

## 5. 판정 보류 확인

| 표시 | 확인할 내용 |
| --- | --- |
| 평가 설정 확인 필요 | 가중치 합 100%, 입력 누락, 분할점수 순서 |
| 빈 점수 또는 숫자가 아닌 점수 | 미입력·결시·인정점 처리 여부. 이 도구는 인정점을 대신 산출하지 않습니다. |
| 환산점 범위 초과 | 원점수 파일 여부, 가중치 설정, 평가 열 연결 |
| 파일 합계와 재계산 합계 불일치 | 두 합계와 평가 열. 소수 둘째 자리 차이 또는 성취도 차이를 확인합니다. |
| 파일 합계 미입력/숫자 아님 | 원본 파일의 합계 칸 |

점수가 모두 빈 학생도 명단에 남습니다. 보류 학생은 A~E·미도달 분포에서 제외하고 인원을 따로 표시합니다. 실제 0점은 빈 점수와 구분합니다.

자퇴·전출은 점수 칸의 해당 문구로 인식합니다. 별도 학적 상태 열만 있는 다른 형식은 자동 인식하지 못할 수 있습니다.

## 6. 결과 저장과 초기화

CSV에는 항목별 원본 값, 재계산 합계, 파일 합계, 반올림 값, 성취도와 보류 사유가 포함됩니다. 학반번호에는 날짜 변환을 줄이기 위해 작은따옴표를 붙이며, 수식처럼 시작하는 텍스트도 작은따옴표로 처리합니다. 스프레드시트의 가져오기 방식에 따라 작은따옴표가 화면에 보일 수 있습니다.

‘초기화’를 누르면 불러온 성적과 결과를 비웁니다. 새 파일을 읽기 시작하거나 읽기에 실패한 경우에도 이전 결과를 내보낼 수 없도록 정리합니다.

## 가상 예제의 예상 결과

기본 설정으로 `examples/sample.csv`를 불러오면 **9명 중 판정 완료 6명, 판정 보류 3명**으로 표시됩니다. A·B·C·D·E·미도달은 각각 1명이며, 나머지는 일부 점수 누락·전체 점수 누락·합계 불일치 사례입니다. 예제의 이름과 점수는 모두 가상입니다.
